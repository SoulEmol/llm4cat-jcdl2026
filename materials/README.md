# Tutorial materials

Materials for the JCDL 2026 tutorial **AI for Organizing Digital Collections: Practical Approaches with LLMs and Vision-Language Models**.

## Contents

- `slides/`: LLM and VLM presentation decks.
- `notebooks/`: hands-on Jupyter notebooks linked from the website through Google Colab.
- `code/`: supporting Python scripts and a downloadable ZIP archive.

The accompanying dataset repository is available at <https://github.com/llm4cat/LLMs>.
